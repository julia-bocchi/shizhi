# 中国计算机设计大赛作品安装说明

作品名称：体重追踪

安装包名称：`entry-default-unsigned.hap`

安装包路径：`entry\build\default\outputs\default\entry-default-unsigned.hap`

一、准备工作：

1．首先准备电脑，并确保电脑能够正常运行，建议使用 Windows 操作系统。

2．在电脑上安装好 DevEco Studio，并完成 HarmonyOS SDK 环境配置。

3．准备一台 HarmonyOS 手机设备，并开启开发者模式和 USB 调试功能。

4．获取本作品工程文件或安装包文件。本作品当前提供的安装包为 `entry-default-unsigned.hap`，属于未签名 HAP 安装包，建议通过 DevEco Studio 编译并签名后安装。

二、安装步骤：

1．使用 DevEco Studio 打开作品工程目录 `hm_test`。

2．连接 HarmonyOS 手机到电脑，确认开发工具已经识别设备。

3．在 DevEco Studio 中配置应用签名信息，并选择对应的运行设备。

4．点击运行或构建，按照提示完成编译、签名、安装和启动。

5．如果采用安装包方式安装，请先生成已签名 HAP 文件，再安装到 HarmonyOS 手机中。

6．安装完成后，在设备应用列表中点击“体重追踪”即可启动程序。

三、注意事项：

1．本作品适用于 HarmonyOS 手机设备，兼容 `API 19`，目标 `API 22`。

2．当前提供的 `entry-default-unsigned.hap` 为未签名安装包，不能直接作为最终真机安装包使用。

3．本作品中的登录、数据同步、饮食计划、训练计划和 AI 助手等功能需要联网环境支持。

4．AI 功能首次使用时需要填写有效的 API Key，否则相关智能问答与推荐功能无法正常使用。

5．如默认后端服务不可用，应用基础界面仍可打开，但部分依赖云端服务的功能可能无法正常使用。
