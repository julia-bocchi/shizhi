2026079861-02 素材与源码

本目录收录作品源码压缩包。

作品名称：智卡管家
应用显示名称：体重追踪

目录内容：
1. 智卡管家_Code.zip
   作品源码总压缩包。

压缩包内容说明：
1. 解压智卡管家_Code.zip后，可得到前端代码.zip与后端代码.rar两个源码归档文件。
2. 前端代码.zip为 HarmonyOS 前端源码，主要包含 ArkTS/ETS 页面、数据模型、工具类、资源文件与测试代码。
3. 后端代码.rar为 Spring Boot 后端源码，主要包含控制器、业务服务、数据实体、Mapper、配置文件与测试代码。

技术栈说明：
1. 前端采用 HarmonyOS ArkUI + ArkTS 开发，主要功能包括登录、首页概览、体重记录、饮食管理、训练管理、个人资料与 AI 助手。
2. 后端采用 Spring Boot + MyBatis-Plus + MySQL 开发，提供用户资料、体重记录、饮食计划、训练计划、训练记录等接口能力。

说明：
1. 本目录以压缩包形式提交源码，便于统一存档与分发。
2. 如需运行项目，请分别解压前端与后端源码后按对应开发环境进行构建与部署。
